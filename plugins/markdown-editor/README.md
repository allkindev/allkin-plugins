# Éditeur markdown

L'éditeur markdown « vivant » d'Allkin : on écrit dans le texte mis en forme, et les marqueurs de
syntaxe (`**`, `#`, `-`…) ne réapparaissent qu'autour du curseur. Pas de bascule entre une source
et un aperçu, pas de cadre : on lit et on écrit au même endroit.

## Où il sert

- **Bloc-notes** — le bouton flottant en bas à droite, ou <kbd>Ctrl</kbd>+<kbd>J</kbd>.
- **Rôle d'un agent** — la section « Rôle » de sa page, et la rédaction du rôle dans l'assistant de
  création d'un agent.
- **Fichiers `.md`** — avec le plugin *Éditeur de texte*, qui s'en sert pour les fichiers markdown.

## Sans ce plugin

Ces éditions n'existent plus : ni bloc-notes, ni section « Rôle » (le `CLAUDE.md` d'un agent reste
en place et continue de servir, il n'est simplement plus modifiable depuis l'interface), et les
fichiers `.md` s'ouvrent comme du texte brut. L'affichage des messages des agents, lui, ne dépend
pas de ce plugin.

## Barre d'outils

Gras, italique, barré, code, titres, listes, cases à cocher, citation, lien, tableau. Chaque bouton
agit sur la sélection, ou insère la balise à l'endroit du curseur.

## Droit demandé

- **Interface d'Allkin** — le plugin s'exécute dans la page d'Allkin, avec ta session.
